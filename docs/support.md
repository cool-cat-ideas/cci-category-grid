# CCI Category Grid support

## Choose the right support channel

We are happy to help if a step is unclear or something is not working as expected. You can describe the situation in your own words.

For a private question, order or licence issue, use [Services and support](https://coolcatideas.com/en/account/services/) in your Cool Cat Ideas account:

1. Sign in, or create an account if you do not have one.
2. Under **Contact the team**, choose **General question**. If your licence includes active technical support, you can instead choose **Technical support for a licence** and select the relevant **Licence**.
3. Enter a subject and describe the issue. A screenshot and the installed product version can help. Please leave out passwords, licence keys and customer data.
4. Click **Send message**. Your conversation opens after submission, and you can return to it under **Your conversations** on the same page.

You can send a general question without an active support licence. For an installation or technical intervention you already purchased, open the item under **Purchased services** and use its linked conversation.

For an unclear documentation step or a broken link, use **Report an issue** on the [online documentation page](https://coolcatideas.com/en/docs/cci-category-grid/1.0.0/support/). It opens the documentation feedback form. To report a security vulnerability, please [email info@coolcatideas.com](mailto:info@coolcatideas.com) rather than posting the details publicly.

Never include passwords, access tokens, customer data or production database exports in a public post.

Describe what you expected and what appeared instead. Include any of these
details you know; you can ask for help without collecting them all:

- module version (`1.0.0` for this documentation);
- exact PrestaShop and PHP versions;
- active theme name and whether it has a module template/CSS override;
- shop and language affected in a multistore setup;
- selected category IDs and the saved image/subcategory settings;
- the expected result and the actual result;
- relevant PrestaShop log entries and browser console/network errors;
- steps that reproduce the issue on a staging copy.

Do not send back-office passwords, database dumps containing customer data or
production access credentials in an ordinary support message. Use temporary,
least-privilege access only when a separate secure support process explicitly
requires it.

If you have a staging copy, comparing the bundled template with your custom
theme styles can help identify a display issue. This is optional; please do
not change your live shop just to prepare a support request.

The module works without a license key. Custom theme implementation,
catalog cleanup and bespoke layouts are development services rather than defects
in the module package.
