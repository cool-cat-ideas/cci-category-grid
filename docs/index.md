# CCI Category Grid 1.0.0

Use CCI Category Grid when you want to show a few important catalog sections on the homepage. You choose the categories. The module can show their images and a short list of subcategories.

## Set up the first grid

1. Install `cci_categorygrid-1.0.0.zip` in **Modules > Module Manager**.
2. Open **Cool Cat Ideas > CCI Category Grid**.
3. Select at least one active category.
4. Choose whether to show category images and subcategories.
5. Set the number of subcategory links shown on each card.
6. Save and open the homepage in a private browser window.

You should see the selected categories in the same order as on the settings page. The module reads your existing catalog. It does not create or edit categories.

If nothing appears, clear the PrestaShop cache and check **Design > Positions**. The module should be attached to `displayHome`.

The module works without a license key. It supports PrestaShop 9.0.0-9.1.5.
