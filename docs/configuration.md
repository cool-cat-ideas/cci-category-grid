# Choose what appears in the category grid

Open **Cool Cat Ideas > CCI Category Grid**.

## Pick the categories

Select only the categories you want customers to notice on the homepage. Save them in the order in which they should appear.

Before selecting a category, check that:

- it is active;
- it belongs to the current shop;
- it has a name and friendly URL in each storefront language;
- it has an image if you plan to show images.

## Choose what each card shows

- **Show category image** displays the category image above or beside the text, depending on the theme.
- **Show subcategories** adds links to direct child categories.
- **Subcategory limit** sets the maximum number of links on one card. Use `0` when you do not want to show any child links.

The module does not pull grandchildren into the list. If a link is missing, check whether that category is a direct child and is active.

## Check the result

1. Save the settings.
2. Clear the PrestaShop cache.
3. Open the homepage in a private window.
4. Check the section on desktop and mobile.
5. Click every category and subcategory link.

If a newly uploaded image is missing, regenerate category thumbnails in **Design > Image Settings**.
