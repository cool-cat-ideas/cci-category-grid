# Extend CCI Category Grid

Start with the smallest supported extension surface for the required change.

| Goal | Supported surface | Read first |
| --- | --- | --- |
| Change spacing, colors or card proportions | Theme CSS loaded after the base stylesheet | [Storefront output](./storefront-output) |
| Change card markup while keeping module data | Theme Smarty template override | [Storefront output](./storefront-output) |
| Render the configured grid from compatible module code | `WidgetInterface::renderWidget()` | [PHP API](./api-reference) |
| Read the normalized template data | `getWidgetVariables()` | [PHP API](./api-reference) |
| Move the homepage section | PrestaShop hook positions | [Hooks reference](./hooks-reference) |

## Template contract

`getWidgetVariables()` is the supported data boundary for the bundled template.
Treat keys documented in the [PHP API](./api-reference) as read-only values.
Escape any additional output in Smarty and preserve links generated by
PrestaShop rather than constructing category URLs manually.

## CSS contract

Keep all custom selectors under `.cci-category-grid`. The module's stylesheet
is registered with handle `cci-categorygrid-base`; an existing theme extension
uses `cci-categorygrid-theme` and a later priority. Do not dequeue the base file
unless the replacement reproduces responsive layout and accessible focus states.

## Unsupported shortcuts

- Do not write directly to the private `CCI_CATEGORYGRID_*` configuration keys.
- Do not call private image or category normalization methods.
- Do not edit module files for one shop's theme changes.
- Do not depend on generated image filenames; use the URLs supplied by the
  widget variables.

The module does not publish custom REST routes, Symfony services or custom
PrestaShop hooks in version 1.0.0.
