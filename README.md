# CCI Category Grid

Choose which categories appear on the PrestaShop homepage. Decide whether each responsive card shows an image and how many subcategory links it contains.

Download the module ZIP from the [Cool Cat Ideas product page](https://coolcatideas.com/products/cci-category-grid/).

## Set it up

1. Download the current CCI Category Grid ZIP from the product page and install it in **Modules > Module Manager**.
2. Open **Cool Cat Ideas > CCI Category Grid**.
3. Select the categories you want to show.
4. Choose whether to display images and subcategories.
5. Save, clear the PrestaShop cache and open the homepage.

If the section is missing, first check that the module is enabled, at least one active category is selected and the module is attached to `displayHome` in **Design > Positions**.

The module works without a license key. It does not change your categories or their images.
